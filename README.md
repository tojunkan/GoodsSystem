# Qt 商品销售管理系统 V4

这是一个 Qt Widgets + SQLite 的商品销售管理系统，可以直接用 Qt Creator 打开运行。

## 默认经理账号

- 用户名：admin
- 密码：123456

## 运行方法

1. 解压项目。
2. 用 Qt Creator 打开 `QtSupermarketSalesSystem.pro`。
3. 配置 Kit。
4. 构建并运行。
5. 第一次运行会自动创建 `supermarket.db`。

## 本版根据你的新要求修改了这些内容

- 经理界面恢复“管理员工”，可以添加员工、删除员工、修改员工信息。
- 商品查询增加“查询依据”下拉框，可按商品编号、商品名称、商品分类、生产商、全部字段查询。
- 商品列表按照商品编号升序展示。
- 添加商品时，如果商品编号只输入数字，会根据分类自动补全：
  - 食品类 + 3 -> F003
  - 生活类 + 3 -> L003
  - 饮料类 + 3 -> D003
  - 日化类 + 3 -> S003
  - 家电类 + 3 -> A003
  - 文具类 + 3 -> W003
  - 其他 + 3 -> O003
- 查询员工销售记录时，不再使用日历，改成年份和月份两个小箭头选择框。
- 销售员界面去掉“刷新商品列表”按钮，销售成功后会自动更新。
- 所有表格取消最后一列自适应，改成固定等宽列。
- 商品价格输入框支持按光标所在位数增减：
  - 光标在整数部分，小箭头按 1 增减
  - 光标在小数点后一位，小箭头按 0.1 增减
  - 光标在小数点后两位，小箭头按 0.01 增减

## 上一版保留功能

- 商品信息表隐藏：ID、上架下架状态、创建时间。
- 商品信息增加：销售量、进货日期、到期日期。
- 进货日期和到期日期使用 `QDateEdit`，可以弹出日期选择。
- 销售员使用“销售员编号”。
- 销售员查询商品后，可点“取消查询状态”恢复为“商品信息：未查询”。
- 表格支持再次点击同一行取消高亮。
- 代码已经拆分成多个 `.h` 和 `.cpp` 文件。

## 数据库兼容说明

如果你之前运行过旧版，目录里可能已有旧的 `supermarket.db`。新版会自动补齐新字段。  
如果想看全新的示例数据，可以先删除运行目录下的 `supermarket.db`，再重新运行程序。
